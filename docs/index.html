Status by phase

Every phase below ships verified, production-grade Rust code with full unit test coverage. Dot color indicates status.

Packet Enginendap-capture, ndap-protocol
Classic & nanosecond PCAP file parser with big-endian support. Wire decoders for Ethernet, IPv4, IPv6, ARP, TCP, UDP, and ICMP (RFC 792/4443).
REAL
Protocol Frameworkndap-protocol
Dissector trait and ProtocolRegistry with built-in DNS (RFC 1035), HTTP/1.x (RFC 7230), and ICMP dissectors with heuristic sniffing.
REAL
Flow Enginendap-flow
Canonical 5-tuple conversation tracking, session metrics (packets, bytes, timestamps), and TCP stream reassembly with out-of-order buffering.
REAL
Detection Enginendap-detect
Built-in detection rules: Port Scan, SYN Flood, ARP Spoofing, DNS Tunneling (Shannon entropy + length), Cleartext Credentials, and C2 Beaconing (periodicity & jitter clustering).
REAL
Threat Intelligencendap-intel
In-memory IOC store (IP, domain, hash), automated remote feed synchronization (HTTP/file), Sigma-lite evaluator, yara-x scanner, and MITRE ATT&CK tags.
REAL
Web UI & APIndap-api
Axum REST API & WebSocket broadcast (/ws/live) with real-time streaming dashboard, packet capture controls, and synthetic traffic generator.
REAL
Plugin Extensibilityplugins/python-sdk
Community Python detection rules execute out-of-process via JSON-lines IPC over stdin/stdout with process isolation in PythonPluginRule.
REAL

Decisions made this pass

Four previously-open questions, resolved and implemented — not left as TODOs.

01
Live capture, cross-platform
Uses the pcap crate — libpcap on Linux/macOS, npcap on Windows. LiveCapture trait now has a real PcapLiveCapture implementation plus list_interfaces().
02
Threat intel format
Plain JSON arrays or CSV (type,value) — no STIX/TAXII/MISP lock-in. Sigma support is a from-scratch minimal evaluator; no count()/timeframe aggregations. YARA is real, via libyara bindings.
03
Frontend stack
htmx + Chart.js from CDN, single embedded HTML file (api/static/dashboard.html, compiled in via include_str!) — stays a single deployable binary, no npm/webpack.
04
Python plugin runtime
Out-of-process, JSON-lines over stdin/stdout. A crashing or malicious plugin can only take down its own process, not the Rust core.

Build & run

# dependencies on Debian / Ubuntu
$ sudo apt-get install libpcap-dev libyara-dev libclang-dev clang

# build workspace
$ cargo build --release

# analyze PCAP with protocol dissection & detection
$ ./target/release/ndap -v path/to/capture.pcap

# run test suite
$ cargo test

# start web dashboard on http://localhost:8080
$ cargo run -p ndap-api
